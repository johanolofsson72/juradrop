# JuraDrop — Design System

> Generated by Project Inception Wizard on 2026-05-25
> Visual reference: the "Resize Images" macOS utility — dark, minimal, dashed-border drop zones.

## Design Personality

**Tone**: brutally minimal, native macOS, calm under pressure.
**Mood**: a tool a stressed law student opens at 23:47 the night before an exam — it must feel quiet, fast, and trustworthy. Zero visual noise. Every pixel earns its place. The window says "drop the document here and I'll handle it" without literally saying it.

## Typography

**Feel**: native macOS. No web fonts, no Google Fonts, no custom loading.

| Use | Font | Reason |
|---|---|---|
| All UI | `-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display"` | macOS system font. Rendered perfectly by WKWebView. |
| Monospace (result preview if needed) | `ui-monospace, "SF Mono", Menlo, monospace` | macOS system mono. |

### Tailwind config

```js
// tailwind.config.js
fontFamily: {
  sans: ['-apple-system', 'BlinkMacSystemFont', '"SF Pro Text"', '"SF Pro Display"', 'system-ui', 'sans-serif'],
  mono: ['ui-monospace', '"SF Mono"', 'Menlo', 'monospace'],
}
```

### Scale

| Token | Size | Line height | Usage |
|---|---|---|---|
| `text-xs` | 11px | 14px | Captions, hints |
| `text-sm` | 13px | 18px | Settings copy, secondary text |
| `text-base` | 15px | 20px | Body, zone labels |
| `text-lg` | 17px | 22px | Section headings |
| `text-xl` | 22px | 26px | Window title (if shown) |

These match macOS's standard font sizes — no inflated web-app text.

**Anti-patterns**: NEVER use Inter, Roboto, Arial, Helvetica, system-ui-alone, or any web font. They will look subtly wrong on macOS.

## Visual Assets

**Strategy**: icons only. No photography, no illustrations, no stock imagery.

| Asset | Source |
|---|---|
| Drop-zone center icon (the down-arrow) | `lucide-react` — `ArrowDownToLine` or `Download` |
| Settings gear | `lucide-react` — `Settings` |
| Close (window close uses native red traffic-light) | N/A — system chrome |
| Success checkmark | `lucide-react` — `Check` |
| Error | `lucide-react` — `AlertCircle` |
| Loading spinner | `lucide-react` — `Loader2` with Tailwind `animate-spin` |
| App icon (Dock + DMG + .icns) | Custom — to be designed; placeholder is the lucide `FileText` |

**Rules**:
- NEVER use emojis as UI icons — always SVG from `lucide-react`.
- Never use a different icon set (Heroicons, Phosphor, FontAwesome) — pick one and stick with it.
- The app icon (`.icns`) is the only place a custom raster image lives.

## Animation & Motion

**Philosophy**: subtle micro-interactions only. The app must feel alive but never busy.

| Interaction | Animation | Duration | Easing |
|---|---|---|---|
| Drop zone idle → hover | `border-color` and `bg-color` transition | 150 ms | `ease-out` |
| File dragged over zone | Border pulses `--color-border-active`, bg lightens | 200 ms loop | `ease-in-out` |
| File released → processing | Spinner fades in, zone bg holds | 300 ms fade | `ease-out` |
| Processing complete → success | Spinner crossfades to checkmark, holds 2s, fades back to idle | 400 ms total | `ease-in-out` |
| Error state | Border + icon turn `--color-error`, holds until next interaction | instant | none |
| Settings panel open | Slide in from right of window, 250 ms | 250 ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| App launch | Fade-in window contents (Tauri default is fine) | — | — |

**Hard rules**:
- NEVER use scale transforms that change layout (`scale-110` etc. on hover). Use color/opacity changes instead.
- NEVER animate scroll position.
- NEVER use bouncy easing (`cubic-bezier` with overshoot) — it's playful, JuraDrop is calm.
- MUST respect `prefers-reduced-motion: reduce` — set animations to `duration-0` and skip the pulse loop entirely.

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0ms !important;
    transition-duration: 0ms !important;
  }
}
```

## Layout Principles

| Property | Value |
|---|---|
| Window size (default) | `640 × 540` (fits 2×3 grid comfortably) |
| Window min size | `560 × 440` |
| Window max size | `800 × 720` (no real benefit going bigger) |
| Resizable | yes, but not maximize-button-eligible |
| Window padding | `24 px` outer |
| Grid gap | `16 px` between drop zones |
| Drop zone aspect | square (`aspect-square`), min `160 × 160` |
| Drop zone border radius | `16 px` (`rounded-2xl`) |
| Drop zone border style | `dashed` width `2px` |
| Drop zone label | `text-base font-medium` below the icon |
| Settings panel width | `320 px` slide-in |

### Grid layout (6 zones, 2×3 or 3×2)

Default: 3 columns × 2 rows on the default window width. Tailwind:

```tsx
<div className="grid grid-cols-3 gap-4 p-6">
  {zones.map(zone => <DropZone key={zone.id} {...zone} />)}
</div>
```

If window is resized below 480 px wide, collapse to 2 columns × 3 rows.

## The Six Drop Zones (v1.0)

| Label (Swedish) | English meaning | System prompt category |
|---|---|---|
| **Till engelska** | To English | Translate Swedish → English |
| **Till svenska** | To Swedish | Translate English → Swedish |
| **Sammanfatta** | Summarize | Condensed summary in original language |
| **Punktlista** | Bullet list | Key points as bullets |
| **Anonymisera** | Anonymize | Replace personal names, addresses, person numbers with `[Person 1]`, `[Adress 1]`, etc. |
| **Förenkla** | Simplify | Rewrite legalese in plain Swedish |

Each zone has its own Ollama system prompt tuned for the task. Prompts live in `src-tauri/src/prompts/` and are versioned alongside code.

## Brand Identity

**Status**: no logo yet. Placeholder is a lucide `Scale` icon (the law-scales symbol) in `--color-accent`. App icon (.icns) needs to be designed before public release.

**Tone of voice (Swedish UI copy)**:
- Direct, no marketing fluff.
- Second person singular (`du`, not the formal `ni`).
- No exclamation marks. No emojis in UI text.
- Errors begin with the problem, not an apology: "Filen kunde inte läsas" not "Ojdå! Tyvärr kunde vi inte läsa filen."

## Anti-Patterns (NEVER do these)

- Never use generic AI-generated aesthetics (purple gradients on white, "Inter on a white card with a subtle shadow", floating chat-bubble icons).
- Never use emojis in UI strings or as icons.
- Never mix different icon sets — `lucide-react` only.
- Never use inline styles when a Tailwind class would do.
- Never override macOS window chrome (no custom title bar).
- Never download web fonts at runtime.
- Never use a scale transform that shifts layout (`hover:scale-110`).
- Never play sounds.
- Never show a stack trace, error code, or English error message to a Swedish user.

## Pre-Delivery Checklist

Before delivering any UI code, verify:
- [ ] Colors come from CSS variables (no ad-hoc hex values).
- [ ] Typography uses the system font stack only (no Inter, no Google Fonts).
- [ ] Icons are from `lucide-react` only.
- [ ] Hover/dragover states provide feedback without layout shift.
- [ ] Light AND dark mode both look correct (test by toggling macOS appearance).
- [ ] Contrast passes WCAG 2.1 AA (4.5:1 for body text, 3:1 for large).
- [ ] `prefers-reduced-motion: reduce` respected.
- [ ] No emojis used as icons or in UI text.
- [ ] Window resizes gracefully down to `560 × 440`.
- [ ] All user-facing text is in Swedish (no leaked English error).
