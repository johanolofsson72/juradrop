# Implementation Plan: Kontakter grouped per person

**Branch**: `main` (solo direct-push) | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/040-kontakter-per-person/spec.md`

## Summary

The Kontakter zone's output changes from per-category grouping (`## Namn` / `## Adresser` / …) to per-person grouping (`## David Dahl` → his category-labeled details), with unattributable details in a final `## Övriga uppgifter` section. Two halves: (1) **instruction half** — rewrite `KONTAKTER_SYSTEM_PROMPT` (model-steered, not guaranteed); (2) **deterministic half** — rewrite `merge_kontakter` in `chunking.rs` (heading-keyed merge: person sections first-seen order, Övriga pinned last, headingless lines folded to Övriga, empty person sections preserved, per-section-only dedup). Plus the three-way mirrored Swedish help copy update (humanizer gate).
